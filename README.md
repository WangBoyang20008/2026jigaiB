# SortingVisualizer 排序算法可视化

## 项目背景与目标

面向数据结构与算法课程的初学者：看书或听课时，排序算法的"比较—交换"过程抽象、难以想象，不同算法的效率差异也缺乏直观感受。

本项目用 Python + Pygame 实现一个交互式排序可视化工具：

- 5 种经典排序（冒泡、插入、快速、归并、堆）逐步动画演示，比较/交换/已就位状态用颜色区分
- 支持开始/暂停、单步、调速、切换规模与算法，实时显示比较与交换计数
- 内置复杂度实测模块，对 4 种输入分布（随机/已排序/逆序/近乎有序）统计比较次数、交换次数与耗时，生成 SVG 曲线报告，将实测数据与理论复杂度对照

## 课程知识与核心设计

### 架构：算法与界面解耦

核心设计是**用 Python 生成器表达算法执行过程**。每个排序算法是一个生成器函数，每次比较或交换后 `yield` 一个 `Step` 数据对象：

```python
@dataclass
class Step:
    array: list          # 当前数组快照
    comparing: tuple     # 正在比较的下标
    swapping: tuple      # 正在交换/写入的下标
    sorted_upto: int     # 已就位的分界
    comparisons: int     # 累计比较次数
    swaps: int           # 累计交换次数
```

带来的好处：

- **界面只负责渲染**：Pygame 每帧从生成器取若干 Step 绘制，不感知算法细节
- **测试不依赖界面**：测试脚本直接消费生成器验证最终数组，无需启动 GUI
- **统计免费获得**：计数随 Step 携带，实测模块复用同一份算法代码，避免"演示一套、统计一套"的不一致

### 算法与复杂度

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡 | O(n²)（本实现未加提前退出） | O(n²) | O(n²) | O(1) | 稳定 |
| 插入 | O(n)（近乎有序时接近） | O(n²) | O(n²) | O(1) | 稳定 |
| 快速（末位枢轴） | O(n log n) | O(n log n) | O(n²)（有序/逆序输入） | O(log n)~O(n) 递归栈 | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |

## 安装与运行

环境：Python 3.10+（开发环境为 Python 3.14.7 / Windows）。

```bash
pip install -r requirements.txt   # 依赖仅 pygame-ce（API 与 pygame 兼容）
cd src
python main.py                    # 启动可视化界面
```

注意：Python 3.14 下官方 pygame 暂无预编译包，故使用社区版 `pygame-ce`；其他版本 Python 用 `pygame` 亦可。

### 界面操作

| 按键 | 功能 |
|------|------|
| 空格 | 开始 / 暂停 |
| → | 暂停时单步执行 |
| R | 重置为新的随机数组 |
| ↑ / ↓ | 调速（1~60 步/帧） |
| Tab | 切换数组规模（20/50/100/200） |
| 1–5 | 切换算法（冒泡/插入/快排/归并/堆） |

### 正确性测试

```bash
python tests/test_algorithms.py
```

每种算法跑 108 个用例（100 组随机数组 + 空、单元素、全同元素、已排序、逆序、含负数等边界），最终结果与内置 `sorted()` 逐一比对。当前全部通过。

### 复杂度实测

```bash
python src/benchmark.py
```

纯标准库实现，无额外依赖。输出：

- `docs/results.csv`：原始数据（n = 50~1600，4 种输入分布，每规模 5 次取平均）
- `docs/benchmark_report.html`：12 张对数坐标 SVG 曲线图，浏览器直接打开

## 实测结果摘要

- 冒泡排序比较次数精确等于 n(n−1)/2（n=1600 时 1,279,200 次），与理论一致
- 快排（末位枢轴）在逆序输入上退化为 O(n²)：n=1600 耗时约 12.7 s，随机输入仅约 19 ms，相差约 660 倍；归并、堆排在各分布下均稳定在 n·log n 量级
- 近乎有序输入下插入排序显著优于冒泡，体现自适应性

## 局限与改进方向

- 快排使用末位枢轴，有序/逆序输入退化明显；可改进为随机枢轴或三数取中，并在界面中对比展示
- 排序时若修改数组需先重置；尚不支持用户手动输入数组
- 冒泡未加"一轮无交换即提前退出"优化，便于与理论值对照
- 计划增加：多算法同屏竞速对比、导出演示 GIF
